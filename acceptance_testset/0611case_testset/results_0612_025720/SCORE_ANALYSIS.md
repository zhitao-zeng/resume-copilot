                                   总结
====================================================================================================

三大扣分根因:

1. 🔴 LLM 编造时间/日期 (3个case归零, 全在PDF场景)
   - 全部发生在有PDF CV的case (S1-DATA, S3-FIN, S3-DATA)
   - PDF OCR质量差 → LLM优化时猜补了原文不存在的时间字段
   - 建议: PDF CV场景降低LLM temperature + 增强日期字段白名单校验

2. 🔴 表达分普遍低 (所有有分case扣20-38分, 满分50)
   - STAR结构缺失 (无量化结果/职责边界不清)
   - 无CV场景纯靠query生成 → 内容单薄
   - Qwen3.5-9B 能力天花板 (72B模型优化效果会更好)

3. 🟡 必填字段缺失 (姓名/电话/邮箱/教育)
   - S2/S4场景query不提供完整信息 → 天然不足
   - 评分惩罚较重 (每个hard_missing -4分)

4. 🟡 reply_text 被 Qwen 思考链污染
   - 所有case以 "Thinking Process: 1. Analyze..." 开头
   - Qwen3.5-9B忽略system prompt的"只输出JSON"约束
   - 回复分(10分满分)普遍只拿6-8分

5. ✅ 修复效果验证: 3个之前score=None的case现在正常评分
   - fix前S1-FIN/S1-AI/S3-AI编造归零 → fix后先清洗再评分, 不再误判
