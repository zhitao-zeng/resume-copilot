## 遇到的问题 & 解决方案

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 榜单始终走 V1 pipeline | `leaderboard.yml` values 段平台不认，env 未传入容器 | `start.sh` 默认值硬编码 v2 |
| 代码修复未进镜像 | Dockerfile 漏 COPY 3 个文件 | 添加 COPY 行 |
| Pod 卡死后 Connection refused | `run_v2_pipeline` 同步阻塞 async 事件循环 | 去掉 `run_in_executor`，直接同步 |
| 请求耗时 8 分钟+ | `stage_score` 仍调用 V1 `audit_resume_core` | `_has_audit=True` 跳过 |
| Audit 400 Bad Request | `max_tokens=4096` + prompt ≥4097 > 8192 | 降为 2560 |
| bullet analysis Pydantic 验证失败 | schema echo bug（bool 变 dict） | `call_llm_typed` → `call_llm_text` |
| 模型加载 33分钟（榜单） | CephFS 网络文件系统 I/O 极慢（~8MB/s） | 未修，属于基础设施 |
| 服务端日志截断 | Python 日志缓冲 | `PYTHONUNBUFFERED=1` |
